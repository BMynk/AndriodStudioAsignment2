# 📚 CSW Books - Android Textbook App

An Android application designed for students to browse, search, and manage textbooks. Built as part of an Android Studio assignment.

## ✨ Features

- **Browse Textbooks** – Explore available books with clean card-based UI
- **Book Details** – View comprehensive information about each textbook
- **Sell Books** – List your own textbooks using a bottom sheet dialog
- **Search & Filter** – Quickly find books by title, author, or course
- **Modern UI** – Material Design with light/dark mode support
- **Fragment-based Navigation** – Clean architecture using Fragments and RecyclerView

## 🛠 Tech Stack

- **Language**: Java
- **IDE**: Android Studio
- **Architecture**: Fragments + RecyclerView + Adapters
- **UI Components**: Material Design, Bottom Sheet, CardView
- **Data**: Custom model classes with sample data
